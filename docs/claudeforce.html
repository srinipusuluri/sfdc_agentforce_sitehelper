Claudeforce: Claude working on Salesforce

How Claude was used to build, test and document this repo: which tool did what, where a human stayed in the loop, and what went wrong along the way.

The toolchain

Claude Code runs in your editor and works in the project folder. It deploys and tests through the Salesforce CLI, and pushes to GitHub with git and gh. Claude in Chrome drives the browser for steps that only exist in a web UI, such as Slack. Pages are published as private artifacts. Anything that needs a secret, a login or a permission click comes back to you.

Instructions for Claude in Chrome

The file docs/slackforce-chrome-instructions.md is a prompt you paste into Claude in Chrome. It creates the Slack app and webhook, stops for each approval, and checks whether the Salesforce and Slack integration is available. Replace the placeholders for your own org URL and Slack workspace ID first.
